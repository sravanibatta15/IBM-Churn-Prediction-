# 🧠 AI-Powered Customer Retention Prediction System

An end-to-end Machine Learning solution designed to **predict customer churn** in the telecom sector.  
This system enables telecom companies to identify customers who are likely to leave and take proactive retention actions — boosting revenue and customer satisfaction.

---

## 🚀 Project Overview

Customer churn directly impacts business revenue and brand value.  
This project uses **AI & Data Science** techniques to analyze customer behavior and predict churn with high accuracy.

🔧 Workflow Pipeline:
✔ Data cleaning & preprocessing  
✔ Outlier detection & handling  
✔ Missing value treatment  
✔ Categorical encoding  
✔ Data balancing using **SMOTE**  
✔ Feature scaling using **StandardScaler**  
✔ Model training with 8 algorithms  
✔ Evaluation of accuracy, F1-Score, and ROC-AUC  
✔ Final model selection and deployment

✅ **XGBoost** achieved the best performance and was selected for deployment.

## 📊 Key Insights from Data Analysis

📌 Customers with **short tenure** churn more  
📌 **Month-to-month** contract users show high churn  
📌 **High monthly charges** → higher churn probability  
📌 **Auto-payment & long-term contracts** reduce churn  
📌 **Electronic check** payment users churn the most  
📌 Customers with tech support & security add-ons are more loyal  

These insights help telecom operators plan better **retention strategies**.

## 🧠 Model Comparison Summary

| Algorithm | Accuracy | F1-Score | AUC | Remarks |
|-----------|----------|----------|-----|---------|
| KNN | Moderate | Low | – | Sensitive to scaling |
| Naive Bayes | Moderate | Low | – | Assumes feature independence |
| Logistic Regression | 0.757 | Moderate | – | Good explainability |
| Decision Tree | Moderate | – | – | Prone to overfitting |
| Random Forest | 0.758 | High | – | Strong ensemble method |
| SVM | Moderate | – | – | Sensitive to imbalance |
| Gradient Boosting | High | 0.60 | 0.72 | Strong performer |
| ✅ **XGBoost (Final)** | **0.797** | **0.60** | **0.729** | ✅ Best accuracy & generalization |

✅ **XGBoost** was selected as the final model due to superior performance.
